# AI Lead Qualification System

## Overview
This project demonstrates an automated AI lead qualification workflow.  
The system captures incoming leads, evaluates them using AI, assigns a lead score, classifies their priority, and stores them automatically in a CRM-style Google Sheet.

The automation also sends email notifications and replies to the lead automatically.

## Problem
Businesses often receive many inquiries but manually reviewing and prioritizing them takes time.  
Important leads can be missed or responded to slowly.

## Solution
This system automatically analyzes each lead using AI and prioritizes them so businesses can focus on the most valuable prospects first.

## Workflow

Google Form  
→ Google Sheets (Form Responses)  
→ Make Automation Scenario  
→ OpenAI Lead Analysis  
→ JSON Parsing  
→ Leads CRM Sheet  
→ Email Notification  
→ Automatic Email Reply to Lead

## Features

• AI lead scoring (0–100)  
• Priority classification (High / Medium / Low)  
• Lead type classification (Hot / Warm / Cold)  
• Automatic CRM lead entry  
• Email notification for new leads  
• Automated response email to the lead

## Technology Used

Make (Automation platform)  
OpenAI API  
Google Sheets  
Gmail integration
